# CodyFormat v0.7.0-beta.1 — Native Formatter Providers

Goal: add optional local formatter integration without weakening CodyFormat's offline-first and safety model.

Acceptance gates:

1. native execution disabled by default
2. fixed provider allowlist only
3. no shell command concatenation
4. timeout and cancellation
5. missing/failing provider falls back to built-in formatter
6. GUI and CLI expose explicit opt-in and status
7. Alpha.1/Alpha.2/Alpha.3 regression tests remain green
8. GitHub release asset is downloaded back and verified before phase acceptance
