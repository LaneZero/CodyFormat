# CodyFormat v0.7.0-alpha.3 — .editorconfig + Profiles v2

## Goal

Make project formatting rules portable and deterministic across GUI/CLI, while introducing a safe versioned profile format.

## .editorconfig scope

Supported properties:

- `indent_style`
- `indent_size`
- `tab_width`
- `end_of_line`
- `insert_final_newline`
- `trim_trailing_whitespace`

Resolution walks parent directories, honors `root = true`, applies parent configs before nearer configs, and supports common glob patterns including brace alternatives such as `*.{py,pyw}`.

CLI uses `.editorconfig` by default. `--no-editorconfig` disables it for one operation. Explicit `--indent` overrides the resolved `indent_size`.

## Profiles v2

Profile files are JSON with `schemaVersion: 2` and contain only formatting, appearance, and output preferences. No executable command field exists.

Features:

- import/export
- built-in profile migration to v2
- user profile library
- CLI profile file/name support
- project profile discovery at `.codyformat/profile.json`
- malformed/unsupported profiles rejected without replacing current settings
