# CodyFormat v0.7.0-alpha.2 — Batch / Folder Formatting

## Status

**ACTIVE**

Previous milestone: `v0.7.0-alpha.1` — completed and maintainer-tested, including the GitHub Release artifact.

## Goal

Add safe recursive project/folder formatting without weakening the single-file CLI or the formatter regression guarantees introduced in alpha.1.

## Required CLI surface

```bash
codyformat ./src --recursive --check
codyformat ./src --recursive --write
codyformat . --recursive --check --include "**/*.cs" --exclude "**/Generated/**"
codyformat ./src --recursive --write --backup
```

## Default excluded directories

```text
.git
bin
obj
artifacts
TestResults
node_modules
```

## Safety rules

- Directory writes require explicit `--write`.
- `--check` is always non-destructive.
- Do not follow directory symlinks/reparse points by default.
- A failure in one file must not cause partial/corrupt writes to unrelated files.
- Existing single-file safe-write behavior must remain intact.
- Backup mode must preserve the original content before replacement.
- Cancellation must stop future writes promptly.
